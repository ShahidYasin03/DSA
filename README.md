# Data Structures and Algorithms

This repository contains my solutions and practice while learning data structures and
algorithms. It includes implementations, LeetCode problems, study plans, coursework,
and smaller experiments.

## Repository Structure

```text
.
├── coursework/         Quiz and course preparation
├── data-structures/    Core data structure implementations
├── leetcode/           LeetCode solutions
│   ├── cpp/            C++ solutions
│   └── python/         Python solutions
├── patterns/           Pattern-printing practice
├── scratch/            Experiments and temporary practice
├── study-plans/        Structured plans such as LeetCode 150
├── .gitignore          Ignored build and temporary files
└── README.md           Project documentation
```

## Topics

The `data-structures/` folder is organized by topic:

- Arrays and 2D arrays
- Binary search
- Linked lists
- Queues and stacks
- Recursion
- Strings
- Trees
- Vectors

Compiled executables and temporary VS Code runner files are excluded from Git.
